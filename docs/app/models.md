# 모델

HearingAid는 [Whisper](https://github.com/ggerganov/whisper.cpp) 음성 인식 모델로 **PC 안에서** 말을 글로 바꿉니다. 소리가 외부 서버로 전송되지 않습니다.
모델은 여러 개 받아 두고 프로필이나 화자에 따라 골라 쓸 수 있습니다.

## 모델 고르기

| 모델 | 크기 | 추천 상황 |
|---|---|---|
| `large-v3-turbo` | 1.6GB | **추천.** 그래픽 카드가 있는 PC. 정확하고 빠름 |
| `large-v3-turbo-q5_0` | 574MB | 용량을 아끼고 싶을 때. 정확도는 거의 비슷 |
| `large-v3-turbo-q8_0` | 874MB | q5_0보다 조금 더 정확한 양자화 |
| `small`, `small-q5_1` | 190~490MB | 그래픽 카드가 없거나 저사양 PC |
| `medium`, `medium-q5_0` | 540MB~1.5GB | small보다 정확, large-v3-turbo보다 느림 |
| `tiny`, `base`, `base-q5_1` | 60~150MB | 빠른 테스트용. 정확도 낮음 |
| `large-v3`, `large-v3-q5_0` | 1.1~3.1GB | 가장 정확하지만 가장 느림 |
| `batisay-ko-turbo-q5_0`, `batisay-ko-turbo-q8_0` | 574~874MB | 한국어만 들을 때. large-v3-turbo를 한국어로 추가 학습한 모델 |

- 이름에 `q5`, `q8`이 붙은 모델은 **양자화** 모델입니다. 같은 모델을 압축해 용량과 메모리를 줄인 것으로, 정확도는 조금만 떨어집니다.
- 큰 모델일수록 정확하지만 느리고 메모리를 많이 씁니다. 말한 뒤 글이 나오기까지 몇 초 이상 걸린다면 더 작은 모델을 써 보세요.
- `batisay-ko-*` 모델은 [BatiAI](https://huggingface.co/batiai/batisay-ko-turbo)가 만든 모델로, HearingAid(MIT)와 별개인 **BatiAI Community License v2**를 따릅니다. 개인·비영리 용도는 무료이고, 외부 서비스 제공·재판매 등 상업적 사용은 BatiAI의 허락이 필요합니다.

## 모델 관리

메인 화면의 **모델** 버튼을 누릅니다.

| 버튼 | 하는 일 |
|---|---|
| **다운로드** | 선택한 모델을 받음. 목록을 더블클릭해도 됨 |
| **취소** | 받는 중인 다운로드를 멈춤 |
| **삭제** | 선택한 모델 파일을 지움 |
| **기본 모델로 지정** | 모든 프로필이 기본으로 쓸 모델로 지정 |

- 처음 받은 모델은 자동으로 기본 모델이 됩니다.
- 한 번에 하나씩 받습니다. 다운로드 중에 창을 닫으면 취소됩니다.
- 캡처 중에는 삭제와 기본 모델 지정을 할 수 없습니다. 정지한 뒤 하세요.

## 프로필별 모델

**⚙ 편집**에서 프로필을 고르고 **모델** 섹션에서 **모델 재정의**를 체크하면, 이 프로필에서만 기본 모델 대신 고른 모델을 씁니다.

예: 평소에는 `large-v3-turbo`, 노트북 배터리로 쓸 때의 프로필에서는 `small`

## 화자별 모델

Discord처럼 말하는 사람을 구분하는 오디오 소스에서는 사람마다 다른 모델을 쓸 수 있습니다.

1. **⚙ 편집**에서 프로필을 고르고 **모델** 섹션의 **화자별 모델** 표로 갑니다.
2. **인식된 화자 추가**를 누르면 지금까지 목록에 나온 화자가 표에 채워집니다. 직접 이름을 입력해도 됩니다.
3. 화자마다 모델을 고르고 **저장**합니다.

- 이름은 메인 화면 목록에 표시되는 화자 이름과 정확히 같아야 합니다.
- 표에 없는 화자는 프로필의 모델(재정의했다면 그 모델, 아니면 기본 모델)을 씁니다.
- 모델을 여러 개 쓰면 그만큼 메모리를 더 씁니다.

## 그래픽 카드(GPU) 가속

Vulkan을 지원하는 그래픽 카드(NVIDIA, AMD, Intel)가 있으면 자동으로 사용합니다. 없으면 CPU로 동작합니다.

- CPU로 동작하면 큰 모델은 많이 느립니다. `small`이나 `q5` 모델을 쓰세요.
- 그래픽 카드가 있는데도 느리다면 그래픽 드라이버를 최신으로 업데이트해 보세요.
- CPU로 동작할 때 쓰는 스레드 수는 `appsettings.json`의 `threads`로 바꿀 수 있습니다.

## 모델 파일 직접 넣기

다른 PC에서 받아 둔 모델을 옮기거나 목록에 없는 모델을 쓰려면, `ggml-<이름>.bin` 파일을 앱 폴더의 `models\` 폴더에 넣으세요.
**모델** 창을 다시 열면 설치된 모델로 표시됩니다. 목록에 없는 모델은 설명에 "직접 추가한 모델"로 나옵니다.
