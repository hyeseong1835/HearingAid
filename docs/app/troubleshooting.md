# 문제 해결

먼저 메인 화면의 **파형**을 열어 보세요. 소리가 앱까지 들어오는지에 따라 원인이 갈립니다.

| 파형 모양 | 뜻 | 볼 곳 |
|---|---|---|
| 완전히 일자 | 소리가 앱으로 들어오지 않음 | [소리가 들어오지 않아요](#소리가-들어오지-않아요) |
| 아주 작게 움직임 | 소리가 너무 작음 | [소리가 너무 작아요](#소리가-너무-작아요) |
| 충분히 움직임 | 소리는 들어오는데 인식이 안 됨 | [소리는 들어오는데 받아 적지 않아요](#소리는-들어오는데-받아-적지-않아요) |

---

## 시작이 안 돼요

### 노란 경고: 오디오 소스가 설정되지 않았습니다

사용 중인 프로필에 오디오 소스가 없습니다. 경고 오른쪽의 **⚙ 오디오 소스 설정**을 누르고, 프로필의 **오디오 소스**를 고른 뒤 **저장 → 이 프로필 사용**을 누르세요.
프로필이 하나도 없다면 위쪽 **+ 새 프로필**로 먼저 만듭니다.

### "입력 장치를 찾을 수 없습니다" / "출력 장치를 찾을 수 없습니다"

프로필에 적힌 장치 이름이 지금 PC에 없습니다. 다른 PC에서 만든 프로필이거나, 장치를 뺐거나, 장치 이름이 바뀐 경우입니다.

1. 오류 창에 지금 PC에 있는 장치 목록이 표시됩니다.
2. **⚙ 편집**에서 프로필의 `deviceKeyword` 목록을 펼쳐 장치를 다시 고르세요.
3. 어떤 장치든 상관없다면 `deviceKeyword`를 비우세요. Windows 기본 장치를 씁니다.

### "입력 장치가 없습니다"

마이크가 연결되지 않았거나 꺼져 있습니다.
Windows **설정 → 시스템 → 소리 → 입력**에서 마이크가 보이는지, **설정 → 개인 정보 → 마이크**에서 데스크톱 앱의 마이크 사용이 허용돼 있는지 확인하세요.

### "프로세스를 찾을 수 없습니다"

"특정 프로그램 소리만"에 고른 프로그램이 실행 중이 아닙니다. 프로그램을 켜고 소리를 한 번 낸 뒤 다시 시작하세요.
오류 메시지에 지금 소리를 내고 있는 프로그램 목록이 함께 표시됩니다.

### "설치된 Whisper 모델이 없습니다"

받아 둔 모델이 없습니다. **모델**에서 하나 이상 받으세요. [모델](models.md) 문서를 참고하세요.

## 소리가 들어오지 않아요

파형이 완전히 일자일 때입니다.

- **PC 소리 전체**: 소리가 실제로 어느 장치로 나가는지 확인하세요. 헤드폰으로 듣는데 `deviceKeyword`가 스피커를 가리키고 있을 수 있습니다. `deviceKeyword`를 비우면 Windows 기본 출력 장치를 따릅니다.
- **특정 프로그램 소리만**: 고른 프로그램이 맞는지 확인하세요. 브라우저는 `chrome`, 엣지는 `msedge`입니다. 프로그램을 재시작했다면 HearingAid도 정지 후 다시 시작하세요.
- **마이크**: Windows 소리 설정에서 마이크 입력 막대가 움직이는지 확인하세요. 거기서도 안 움직이면 마이크나 드라이버 문제입니다.
- **Discord**: [Discord 봇 설정](discord.md)의 문제 해결을 보세요.

## 소리가 너무 작아요

파형이 아주 작게만 움직일 때입니다.

- 프로필의 `autoGain`(자동 증폭)이 켜져 있는지 확인하세요. 켜 두면 작은 소리를 최대 100배까지 키웁니다.
- Windows **볼륨 믹서**에서 해당 프로그램의 볼륨이 낮게 잡혀 있지 않은지 확인하세요. "PC 소리 전체"와 "특정 프로그램 소리만"은 볼륨 믹서의 크기대로 들어옵니다.
- 마이크라면 Windows 소리 설정에서 마이크 입력 볼륨을 올리세요.

## 소리는 들어오는데 받아 적지 않아요

- 처음 시작할 때는 모델을 불러오느라 몇 초 걸립니다. 상태 표시줄에 "listening..."이 나올 때까지 기다리세요.
- 말소리 감지 기준이 너무 엄격할 수 있습니다. 프로필의 `vadThreshold`를 0.5 정도로 낮춰 보세요.
- 음악 위에 말이 겹친 소리는 말소리로 잘 판단되지 않습니다.
- 인식 언어가 맞는지 확인하세요. 앱 폴더의 `appsettings.json`에 있는 `language`가 `ko`면 한국어로 인식합니다.

## 말하지 않았는데 엉뚱한 문장이 나와요

Whisper 모델은 잡음이나 조용한 소리를 억지로 문장으로 바꾸는 경우가 있습니다("시청해 주셔서 감사합니다" 등).

- 잡음이 많은 마이크라면 `autoGain`을 끄세요. 자동 증폭이 잡음까지 키웁니다.
- `vadThreshold`를 0.8 정도로 올리세요.
- `minSpeechMs`를 늘리면 짧은 잡음이 걸러집니다.
- 작은 모델일수록 이런 일이 잦습니다. 가능하면 `large-v3-turbo`를 쓰세요.

## 받아 적기가 너무 느려요

말한 뒤 글이 나오기까지 오래 걸리거나, 흐린 `…` 줄이 계속 쌓일 때입니다.

- 그래픽 카드가 없으면 큰 모델은 느립니다. **모델**에서 `small`이나 이름에 `q5`가 붙은 모델을 받아 기본 모델로 지정하세요.
- 그래픽 카드가 있다면 그래픽 드라이버를 최신으로 업데이트하세요. Vulkan을 쓰지 못하면 CPU로 동작합니다.
- 화자별 모델로 큰 모델을 여러 개 쓰고 있다면 하나로 줄여 보세요.

## 문장이 이상하게 끊기거나 붙어요

[오디오 소스 설정](audio-sources.md)의 "말소리 감지" 표를 보고 `minSilenceMs`, `minSpeechMs`, `speechPadMs`를 조정하세요.

## 프로그램이 목록에 없어요

"특정 프로그램 소리만"의 목록에는 **실행 중이고 소리를 낸 적이 있는** 프로그램만 나옵니다.
영상을 잠깐 재생한 뒤 목록을 다시 펼치세요. 목록에 없어도 프로세스 이름을 직접 적을 수 있습니다.

## 마이크가 목록에 없어요

마이크를 꽂은 뒤 `deviceKeyword` 목록을 다시 펼치세요. 펼칠 때마다 새로 찾습니다.
그래도 없다면 Windows 소리 설정에서 장치가 "사용 안 함"으로 돼 있지 않은지 확인하세요.

## 모델 다운로드가 실패해요

- 인터넷 연결을 확인하고 다시 **다운로드**를 누르세요. 중간에 실패한 파일은 자동으로 지워집니다.
- 회사·학교 네트워크에서는 `huggingface.co`가 막혀 있을 수 있습니다. 다른 곳에서 받은 `ggml-<이름>.bin` 파일을 앱 폴더의 `models\`에 직접 넣어도 됩니다.
- 디스크 공간이 충분한지 확인하세요. `large-v3-turbo`는 1.6GB가 필요합니다.

## 업데이트가 실패해요

- 인터넷 연결을 확인하고 **업데이트** 버튼으로 다시 시도하세요.
- 앱 폴더가 `C:\Program Files`처럼 쓰기가 제한된 곳에 있으면 파일을 바꿀 수 없습니다. 바탕 화면이나 문서 폴더로 옮기세요.
- 그래도 안 되면 GitHub Releases에서 새 zip을 받아, 기존 폴더에 덮어쓰세요. 이때 `appsettings.json`, `profiles\`, `models\`는 덮어쓰지 않도록 주의하세요.

## 설정을 처음 상태로 되돌리고 싶어요

- 프로필 하나만: **⚙ 편집**에서 그 프로필을 삭제하고 새로 만드세요.
- 설정 하나만: 그 설정의 **기본값으로 재설정**을 누르세요.
- 전부: 앱을 끄고 앱 폴더의 `profiles\` 폴더를 지우세요. 받아 둔 모델(`models\`)은 그대로 둬도 됩니다.
