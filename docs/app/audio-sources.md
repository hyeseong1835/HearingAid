# 오디오 소스 설정

오디오 소스는 "어디서 나는 소리를 받아 적을지"입니다. 프로필마다 하나씩 고릅니다.
설정은 **⚙ 편집**에서 프로필을 고르면 맨 위에 표시됩니다.

- 각 설정 아래에 짧은 설명이 붙어 있습니다.
- 기본값에서 바꾼 설정은 왼쪽에 파란 줄이 생기고, **기본값으로 재설정**으로 되돌릴 수 있습니다.
- 바꾼 뒤에는 **저장**을 누르세요. 캡처 중이라면 정지 후 다시 시작해야 반영됩니다.

## 여러 소스 동시에 쓰기

한 프로필에 오디오 소스를 여러 개 넣어 동시에 받아 적을 수 있습니다. 예: 회의 앱 소리(특정 프로그램 소리만) + 옆 사람 목소리(마이크).

1. **⚙ 편집**에서 프로필을 고르면 오디오 소스 위쪽에 소스별 탭이 있습니다. 끝의 **+ 추가** 탭을 누릅니다.
2. 새로 생긴 **2** 탭에서 종류를 고르고 설정한 뒤 **저장**합니다.
3. 탭을 누르면 그 소스의 설정만 아래에 표시됩니다. 필요 없는 소스는 머리글 오른쪽의 **✕ 제거**로 뺍니다.

- 소스마다 **별명**을 붙일 수 있습니다(예: `회의`, `내 마이크`). 비워 두면 종류의 시스템 이름(`WasapiLoopback`, `ProcessLoopback`, `WaveIn`, `NetCord`)이 별명이 됩니다.
- 소스가 2개 이상이면 메인 화면 목록에 **소스** 칸이 생겨, 각 줄이 어느 소스에서 왔는지 별명과 색으로 표시됩니다.
- 상태 표시줄의 메시지 앞에도 `[회의]`처럼 별명이 붙습니다.
- 내보내기(TXT/CSV)에도 소스 별명이 함께 저장됩니다.
- 같은 종류를 두 개 쓴다면 별명을 다르게 지정해 두세요. 별명이 겹치면 탭에 ⚠가 붙고 탭 아래에 경고가 표시됩니다(저장은 됩니다).
- 탭을 끌어 다른 탭 위에 놓으면 순서가 바뀝니다. 순서가 곧 소스 번호이며, **저장**해야 반영됩니다.
- 하나라도 시작하지 못하면 전체가 시작되지 않고, 오류 메시지에 몇 번 소스가 문제인지 표시됩니다.
- 종류를 고르지 않은 소스는 저장할 때 빠집니다.
- 같은 소리를 두 소스가 함께 받으면(예: "PC 소리 전체" + "특정 프로그램 소리만"으로 같은 브라우저) 같은 말이 두 번 적힙니다.

## PC 소리 전체

스피커·헤드폰으로 나오는 소리를 모두 받아 적습니다. 따로 설치할 것이 없습니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| `deviceKeyword` | (비움) | 캡처할 출력 장치. 목록에서 고르거나 이름 일부를 적음. 비워 두면 Windows 기본 출력 장치 |

- 알림음, 음악 등 모든 소리가 함께 들어갑니다. 한 프로그램만 듣고 싶다면 "특정 프로그램 소리만"을 쓰세요.
- 헤드폰과 스피커를 번갈아 쓴다면 `deviceKeyword`를 비워 두세요. 그때그때 Windows 기본 장치를 따라갑니다. 단, 캡처 중에 기본 장치를 바꾸면 정지 후 다시 시작해야 합니다.

## 특정 프로그램 소리만

고른 프로그램에서 나오는 소리만 받아 적습니다. Windows 10 2004 이상이 필요합니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| `processName` | (필수) | 캡처할 프로그램. 목록에서 고르거나 프로세스 이름(예: `chrome`, `msedge`, `Zoom`)을 적음 |

- 목록에는 **지금 실행 중이고 소리를 낸 적이 있는** 프로그램만 나옵니다. 원하는 프로그램이 없으면 그 프로그램에서 영상 등을 잠깐 재생한 뒤 목록을 다시 펼치세요.
- 크롬·엣지처럼 프로세스가 여러 개인 프로그램은 자동으로 소리를 내는 쪽을 찾고, 그 하위 프로세스의 소리도 함께 받습니다.
- 시작할 때 프로그램이 실행 중이어야 합니다. 프로그램을 껐다 켰다면 정지 후 다시 시작하세요.

## 마이크 등 입력 장치

마이크처럼 PC로 들어오는 소리를 받아 적습니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| `deviceKeyword` | (비움) | 사용할 입력 장치. 목록에서 고르거나 이름 일부를 적음. 비워 두면 Windows 기본 입력 장치 |
| `bufferMilliseconds` | 32 | 장치에서 소리를 받아오는 단위. 소리가 끊기면 늘림 |

- 목록은 펼칠 때마다 새로 찾습니다. 마이크를 방금 꽂았다면 목록을 다시 펼치세요.
- 장치 이름은 Windows 제한으로 앞 31글자까지만 표시됩니다. 이름 일부만 적어도 찾으므로 문제없습니다.
- VB-CABLE 같은 가상 오디오 케이블로 소리를 돌려 받을 때도 이 소스를 쓰고, `CABLE Output` 장치를 고릅니다.

Discord 봇을 음성 채널에 들여보내 **말하는 사람별로** 받아 적습니다. 처음 한 번 봇을 만들어야 합니다.
설정 방법은 [Discord 봇 설정](discord.md) 문서를 보세요.

## 공통 설정

모든 오디오 소스에 있는 설정입니다. 대부분 기본값 그대로 두면 됩니다.

### 소리 크기

| 설정 | 기본값 | 설명 |
|---|---|---|
| `autoGain` | 켜짐 | 자동 증폭. 들어오는 소리가 작으면 최대 100배까지 자동으로 키움. 큰 소리는 줄이지 않음 |
| `gain` | 1.0 | 고정 증폭 배율. 2.0이면 2배. 자동 증폭과 함께 쓰면 먼저 곱해짐 |

- 앱이나 플레이어 볼륨이 낮아 **파형**이 거의 일자라면 `autoGain`을 켜 두세요.
- 조용한 방의 마이크처럼 잡음이 많다면 `autoGain`이 잡음까지 키워 엉뚱한 문장이 나올 수 있습니다. 이때는 끄세요.

### 말소리 감지 (VAD)

HearingAid는 소리를 계속 받아 적지 않고, **말소리로 판단된 구간만** 잘라서 인식합니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| `vadThreshold` | 0.7 | 말소리로 판단하는 기준(0~1). 높을수록 엄격 |
| `minSilenceMs` | 600 | 이만큼(ms) 조용하면 한 문장이 끝난 것으로 봄 |
| `speechPadMs` | 200 | 말 시작 직전 소리를 이만큼(ms) 더 포함 |
| `minSpeechMs` | 500 | 이보다 짧은 소리는 버림(기침, 키보드 소리 등) |

어떻게 바꿀지:

| 증상 | 조정 |
|---|---|
| 말을 하는데 잘 안 잡힘 | `vadThreshold`를 0.5 정도로 낮춤 |
| 음악·잡음이 말로 잡힘 | `vadThreshold`를 0.8 정도로 올림 |
| 한 문장이 여러 줄로 쪼개짐 | `minSilenceMs`를 900~1200으로 늘림 |
| 여러 문장이 한 줄로 길게 붙음 | `minSilenceMs`를 300~400으로 줄임 |
| 짧은 대답("네", "응")이 빠짐 | `minSpeechMs`를 200~300으로 줄임 |
| 문장 첫 글자가 잘림 | `speechPadMs`를 300~400으로 늘림 |

### 고급

| 설정 | 기본값 | 설명 |
|---|---|---|
| `pumpIntervalMs` | 100 | 캡처한 소리를 내보내는 주기(ms). 짧을수록 지연이 줄지만 CPU를 더 씀 |
| `bufferSeconds` | 5.0 | 처리가 밀릴 때 소리를 쌓아 둘 수 있는 길이(초) |

"PC 소리 전체"와 "특정 프로그램 소리만"에만 있습니다. 바꿀 일은 거의 없습니다.

## 프로필의 모델 설정

프로필 편집 화면 왼쪽 섹션 목록의 **모델**에서 정합니다.

- **모델 재정의**: 이 프로필에서만 기본 모델 대신 다른 모델을 씁니다.
- **화자별 모델**: 말하는 사람마다 다른 모델을 씁니다. Discord처럼 화자를 구분하는 소스에서만 의미가 있습니다.

자세한 내용은 [모델](models.md) 문서를 보세요.
