# 시작하기

HearingAid는 PC에서 나는 소리나 마이크, Discord 음성 채널의 말을 실시간으로 받아 적습니다.
처음 쓸 때는 아래 순서대로 한 번만 설정하면 됩니다.

1. 음성 인식 모델 받기
2. 프로필을 만들고 오디오 소스(무엇을 들을지) 고르기
3. **시작** 누르기

---

## 1. 모델 받기

처음 실행하면 **모델 선택** 창이 뜹니다.

- 잘 모르겠다면 굵게 표시된 추천 모델 `large-v3-turbo`(약 1.6GB)를 고르고 **다운로드**를 누르세요.
- 그래픽 카드가 없거나 오래된 PC라면 `small`이나 이름에 `q5`가 붙은 모델이 낫습니다.
- 다운로드가 끝나면 **HearingAid 시작 ▶**을 누릅니다.

나중에 메인 화면의 **모델** 버튼으로 다른 모델을 더 받거나 지울 수 있습니다. 자세한 내용은 [모델](models.md) 문서를 보세요.

## 2. 프로필 만들기

프로필은 "무엇을 어떻게 들을지"를 저장해 둔 묶음입니다. 예를 들어 `유튜브`, `회의`, `디스코드` 프로필을 만들어 두고 상황에 따라 바꿔 씁니다.

1. 메인 화면 위쪽의 **⚙ 편집**을 누릅니다.
2. 위쪽 **+ 새 프로필**을 누르고 이름을 입력합니다.
3. 왼쪽 섹션 목록에서 **오디오 소스**를 열고, 무엇을 들을지 종류를 고릅니다. (**모델**, **고급** 섹션은 필요할 때만 엽니다.)

   | 오디오 소스 | 이럴 때 |
   |---|---|
   | PC 소리 전체 | 스피커·헤드폰으로 나오는 소리를 모두 받아 적을 때 |
   | 특정 프로그램 소리만 | 크롬, Zoom처럼 한 프로그램의 소리만 받아 적을 때 |
   | 마이크 등 입력 장치 | 옆 사람의 말을 마이크로 받아 적을 때 |
   | Discord 음성 채널 | Discord 통화를 말하는 사람별로 받아 적을 때 |

   각 소스의 설정은 [오디오 소스 설정](audio-sources.md)에 정리돼 있습니다.
4. 아래 설정을 필요한 만큼 바꾸고 **저장**을 누릅니다. 대부분은 기본값 그대로 두면 됩니다.
5. 오른쪽 위 **이 프로필 사용**을 누르고 창을 닫습니다. 사용 중인 프로필을 고쳤다면 같은 자리의 **변경 적용**을 누르면 바로 반영됩니다.

오디오 소스를 고르지 않은 프로필은 목록에 ⚠ 표시가 붙고, 메인 화면 위쪽에 노란 경고가 표시됩니다.

## 3. 받아 적기

- **▶ 시작**을 누르면 들리는 말이 목록에 한 줄씩 나타납니다.
  - 말이 끝난 직후에는 흐린 `…`로 표시됐다가, 인식이 끝나면 글로 바뀝니다.
  - 처음 시작할 때는 모델을 불러오느라 몇 초 걸립니다.
- **■ 정지**를 누르면 멈춥니다.
- 다른 프로필로 바꾸려면 정지한 상태에서 메인 화면의 **프로필** 목록에서 고릅니다.

## 화면 구성

| 버튼 | 하는 일 |
|---|---|
| **▶ 시작 / ■ 정지** | 받아 적기를 시작하거나 멈춤 |
| **프로필** 목록 | 사용할 프로필을 바로 전환 (정지한 상태에서) |
| **⚙ 편집** | 프로필 추가·삭제, 오디오 소스·모델 설정 |
| **파형** | 들어오는 소리의 크기를 그래프로 표시. 받아 적기가 안 될 때 확인용 |
| **모델** | 모델 다운로드·삭제, 기본 모델 지정 |
| **내보내기** | 받아 적은 내용을 TXT 또는 CSV 파일로 저장 |
| **지우기** | 목록을 비움 (저장된 파일에는 영향 없음) |
| **새로고침** | 목록을 다시 그림 |
| **문서** | 이 설명서 (단축키 F1) |
| **업데이트** | 새 버전 확인 및 설치 |

아래쪽 상태 표시줄에는 지금 무엇을 하고 있는지(모델 불러오는 중, 듣는 중, 오류 등)가 표시됩니다.
**자동 스크롤**을 끄면 새 글이 나와도 목록이 따라 내려가지 않습니다.

## 업데이트

새 버전이 나오면 실행할 때 알림 창이 뜹니다. **업데이트 후 재시작**을 누르면 받아서 설치하고 다시 켭니다.

- 프로필, 설정, 받아 둔 모델은 그대로 유지됩니다.
- 캡처 중이었다면 업데이트 전에 멈춥니다.
- 실행할 때 확인하지 않으려면 앱 폴더의 `appsettings.json`에서 `"checkForUpdates": false`로 바꾸세요. **업데이트** 버튼으로는 언제든 직접 확인할 수 있습니다.

## 설정 파일

모든 설정은 앱 폴더에 저장됩니다. 보통은 직접 고칠 필요가 없습니다.

| 파일 / 폴더 | 내용 |
|---|---|
| `appsettings.json` | 앱 전체 설정 (아래 표) |
| `profiles\` | 프로필마다 하나씩 있는 `.json` 파일 |
| `models\` | 받아 둔 음성 인식 모델 |

`appsettings.json`의 항목:

| 항목 | 기본값 | 설명 |
|---|---|---|
| `language` | `ko` | 인식할 언어. `en`(영어), `ja`(일본어) 등. `auto`면 자동 감지 |
| `threads` | `4` | CPU로 인식할 때 쓸 스레드 수 |
| `checkForUpdates` | `true` | 실행할 때 새 버전 확인 |
| `model` | (없음) | 기본 모델. **모델** 화면의 "기본 모델로 지정"이 기록함 |
| `activeProfile` | (없음) | 사용 중인 프로필. **이 프로필 사용**이 기록함 |

앱 폴더를 통째로 다른 곳으로 옮겨도 그대로 동작합니다. 다른 PC로 옮길 때 Discord 프로필이 있다면 봇 토큰이 함께 옮겨지니 주의하세요.
