# Discord 음성 채널 받아 적기

HearingAid는 Discord 봇을 음성 채널에 들여보내 채널의 말을 받아 적을 수 있습니다.
PC 소리를 캡처하는 방식과 달리 **말하는 사람마다 따로** 받아 적어서, 목록에 누가 말했는지가 함께 표시됩니다.

동작 방식은 이렇습니다.

1. 내가 만든 봇이 Discord에 접속합니다.
2. 봇이 들어가 있는 서버 중에서 **지정한 사용자(보통 나)** 가 있는 음성 채널을 찾아 같이 들어갑니다.
3. 그 사용자가 다른 채널로 옮기면 따라가고, 음성 채널을 나가면 기다립니다.

처음 한 번만 봇을 만들어 두면, 그다음부터는 HearingAid에서 **시작**만 누르면 됩니다.

### 필요한 권한 한눈에 보기

봇은 음성 채널에 들어가 **듣기만** 합니다. 말하거나 메시지를 보내지 않으므로 권한은 최소한만 줍니다.

| 구분 | 설정 | 값 |
|---|---|---|
| OAuth2 Scope | `bot` | 체크 |
| OAuth2 Scope | `applications.commands` 등 나머지 | 체크하지 않음 |
| Bot Permissions | `View Channels` (채널 보기) | **필요**. 음성 채널 목록과 대상 사용자가 있는 채널을 보기 위해 |
| Bot Permissions | `Connect` (연결) | **필요**. 음성 채널에 들어가기 위해 |
| Bot Permissions | `Speak`, `Send Messages`, `Administrator` 등 나머지 | 필요 없음. 주지 마세요 |
| Privileged Gateway Intents | `Presence`, `Server Members`, `Message Content` | 모두 **끔**. HearingAid는 특권이 없는 `Guilds`, `GuildVoiceStates` 인텐트만 씀 |
| 서버 설정 | 봇의 서버 헤드셋 음소거(Server Deafen) | **꺼져 있어야 함**. 켜져 있으면 소리를 받을 수 없음 |

권한 정수로는 `1049600`(View Channels 1024 + Connect 1048576)입니다.

> **먼저 알아둘 점**
> 봇은 음성 채널 참가자 목록에 다른 사람에게도 보입니다. 다른 사람의 말을 받아 적는 것이므로, 함께 있는 사람들에게 미리 알리고 동의를 받으세요.

## 1. 봇 만들기 (처음 한 번)

### 1-1. 애플리케이션 만들기

1. [Discord 개발자 포털](https://discord.com/developers/applications)에 Discord 계정으로 로그인합니다.
2. 오른쪽 위 **New Application**을 누르고 이름(예: `HearingAid`)을 정합니다. 이 이름이 음성 채널에 표시되는 봇 이름이 됩니다.
3. 약관에 동의하고 **Create**를 누릅니다.

### 1-2. 봇 토큰 받기

1. 왼쪽 메뉴에서 **Bot**을 엽니다.
2. **Reset Token**을 누르고 확인하면 토큰이 한 번만 표시됩니다. **Copy**로 복사해 메모장 등에 잠시 붙여 두세요.
   - 토큰은 봇의 비밀번호입니다. 다른 사람에게 보여주거나 인터넷에 올리지 마세요.
   - 잃어버렸거나 유출됐다면 다시 **Reset Token**을 누르세요. 예전 토큰은 즉시 무효가 되고, HearingAid에는 새 토큰을 넣으면 됩니다.
3. 같은 화면의 **Privileged Gateway Intents**(Presence / Server Members / Message Content)는 **켜지 않아도 됩니다.**

### 1-3. 봇을 서버에 초대하기

봇을 초대하려면 그 서버에 대한 **서버 관리하기** 권한이 필요합니다. 내 서버가 아니라면 서버 관리자에게 아래 링크를 전달해 초대를 부탁하세요.

1. 왼쪽 메뉴에서 **OAuth2**를 열고 **OAuth2 URL Generator**로 내려갑니다.
2. **Scopes**에서 `bot`을 체크합니다.
3. 아래 **Bot Permissions**에서 다음 두 가지만 체크합니다.
   - `View Channels` (채널 보기)
   - `Connect` (음성 채널 연결)

   말할 필요가 없으므로 `Speak`는 필요 없습니다. 관리자 권한도 주지 마세요.
4. 맨 아래 **Generated URL**을 복사해 브라우저에서 엽니다.
5. 봇을 넣을 서버를 고르고 **승인**을 누릅니다.

여러 서버에서 쓰려면 서버마다 같은 링크로 초대하면 됩니다.

> **링크를 직접 만들 수도 있습니다.** 개발자 포털 **General Information**의 **Application ID**를 복사해 아래 주소의 `<APPLICATION_ID>` 자리에 넣으세요.
> `https://discord.com/oauth2/authorize?client_id=<APPLICATION_ID>&scope=bot&permissions=1049600`

### 1-4. 채널별 권한 확인

서버 전체 권한이 있어도 **채널마다** 권한을 따로 막아 둘 수 있습니다. 봇이 들어가지 못하는 채널이 있다면 확인하세요.

1. 음성 채널 옆 톱니바퀴 → **권한**을 엽니다.
2. `@everyone` 또는 봇이 속한 역할에 **채널 보기**나 **연결**이 ❌(거부)로 돼 있으면 봇이 들어갈 수 없습니다.
3. **역할/멤버 추가**로 봇(또는 봇 역할)을 추가하고 **채널 보기**와 **연결**을 ✅(허용)로 바꿉니다.

비공개 카테고리에 있는 채널도 같은 방법으로 봇을 허용해야 합니다.

## 2. 내 Discord 사용자 ID 확인 (처음 한 번)

HearingAid는 봇이 따라다닐 사람을 **사용자 ID**(숫자)로 지정합니다. 보통은 내 ID를 넣습니다.

1. Discord 앱에서 **사용자 설정(톱니바퀴) → 고급**으로 가서 **개발자 모드**를 켭니다.
2. 왼쪽 아래 내 프로필(또는 채팅 목록의 내 이름)을 **우클릭 → 사용자 ID 복사**를 누릅니다.

`123456789012345678`처럼 17~20자리 숫자가 복사됩니다.

## 3. HearingAid 설정

1. HearingAid 메인 화면에서 프로필 목록 옆의 **⚙ 편집** 버튼을 누릅니다.
2. 위쪽 **+ 새 프로필**을 누르고 이름(예: `디스코드`)을 입력합니다.
3. 새 프로필을 고르고, **오디오 소스** 섹션에서 종류를 **Discord 음성 채널 (NetCord)** 로 고릅니다.
4. 다음 두 칸을 채웁니다.

   | 설정 | 넣을 값 |
   |---|---|
   | `token` | 1-2에서 복사한 봇 토큰 |
   | `targetUserId` | 2에서 복사한 사용자 ID |

   `token` 칸은 화면 공유 중에도 보이지 않도록 가려서 표시됩니다. 옆의 **보기**를 체크하면 잠깐 확인할 수 있습니다.

   나머지 설정은 기본값 그대로 두면 됩니다. 각 설정의 뜻은 아래 [설정 항목](#설정-항목)에 정리했습니다.
5. **저장**을 누른 뒤 오른쪽 위 **이 프로필 사용**을 누릅니다. 캡처가 멈춰 있어야 프로필을 바꿀 수 있습니다.
6. 프로필 창을 닫고 메인 창에서 **시작**을 누릅니다.

### 시작 후 흐름

아래 상태 메시지는 메인 창 아래쪽 상태 표시줄에 차례로 나타납니다.

| 상태 메시지 | 의미 |
|---|---|
| `Discord 게이트웨이 연결됨 — 대상 사용자 탐색 중...` | 봇이 Discord에 접속했습니다. 2초 정도 서버 목록을 받습니다. |
| `음성 채널 참가 중...` | 대상 사용자가 있는 음성 채널을 찾아 들어가는 중입니다. |
| `Discord 음성 채널 (...) — listening...` | 받아 적기 준비가 끝났습니다. 누군가 말하면 목록에 나타납니다. |
| `대상 사용자가 음성 채널에 없습니다. 대기 중...` | 대상 사용자가 음성 채널에 없습니다. 들어가면 봇이 자동으로 따라 들어갑니다. |

대상 사용자가 다른 채널로 옮기면 봇도 따라 옮깁니다. 채널을 나가면 봇도 나가서 기다립니다.

## 4. 화자 이름과 화자별 설정

- 처음 말한 사람은 자동으로 `knownUsers` 목록에 추가되고, 이름은 다음 순서로 채워집니다.
  1. 서버 별명
  2. 표시 이름
  3. 사용자명
- 이름을 아직 못 가져왔다면 잠깐 동안 사용자 ID(숫자)로 표시됩니다.
- 이름을 바꾸려면 프로필 설정의 `knownUsers` 표에서 `name` 칸을 고친 뒤 **저장**하세요. 캡처 중이어도 다음 발화부터 바뀐 이름으로 표시됩니다.
- `knownUsers`의 `gain`, `lowPassCutoffHz`, `lowPassQ`는 사람별 소리 보정값입니다. 다시 **시작**해야 반영됩니다.
- **화자별 모델**: 프로필 설정의 "화자별 모델" 표에서 화자 이름마다 다른 Whisper 모델을 지정할 수 있습니다.
  - 예: 발음이 빠른 사람만 큰 모델 쓰기
  - **인식된 화자 추가**를 누르면 지금까지 말한 사람들이 표에 채워집니다.
  - 이름은 목록에 표시되는 이름과 정확히 같아야 합니다.

## 설정 항목

| 설정 | 기본값 | 설명 |
|---|---|---|
| `token` | (필수) | 봇 토큰 |
| `targetUserId` | (필수) | 봇이 따라다닐 사용자의 ID |
| `knownUsers` | 비어 있음 | 화자 목록(`userId`/`name`/`gain`/`lowPassCutoffHz`/`lowPassQ`). 비워 두면 말하는 사람이 자동으로 추가됨 |
| `gain` | 1.0 | 새로 추가되는 화자의 기본 증폭 배율 |
| `autoGain` | 켜짐 | 작은 목소리를 자동으로 키움. 화자마다 따로 맞춤 |
| `lowPassCutoffHz`, `lowPassQ` | 7000, 0.707 | 음질 변환용 필터. 보통 그대로 둠 |
| `vadThreshold` | 0.7 | 말소리 판단 기준(0~1). 잡음이 말로 잡히면 올리고, 말이 잘 안 잡히면 내림 |
| `minSilenceMs` | 600 | 이만큼 조용하면 한 문장이 끝난 것으로 봄 |
| `speechPadMs` | 200 | 말 시작 직전 소리를 이만큼 더 포함 |
| `minSpeechMs` | 500 | 이보다 짧은 소리는 버림(기침, 키보드 소리 등) |

## 문제 해결

**계속 `대상 사용자가 음성 채널에 없습니다. 대기 중...`이 뜹니다.**
- 대상 사용자가 실제로 음성 채널에 들어가 있는지 확인하세요.
- 봇이 **그 서버에 초대돼 있는지** 확인하세요. 서버 멤버 목록에 봇이 보여야 합니다.
- `targetUserId`가 맞는지 확인하세요. 서버 ID나 채널 ID를 넣는 실수가 흔합니다.

**`음성 채널 참가 실패`가 뜹니다.**
- 봇 역할에 그 음성 채널의 **채널 보기**와 **연결** 권한이 있는지 확인하세요. 채널별 권한 설정에서 막혀 있을 수 있습니다.
- 음성 채널에 인원 제한이 있고 꽉 찼다면 봇이 들어갈 수 없습니다.

**시작하자마자 오류가 나거나 접속이 안 됩니다.**
- 토큰이 틀렸거나 재발급돼 무효일 수 있습니다. 1-2에서 새로 받아 넣으세요.
- 토큰 앞뒤에 공백이 섞이지 않았는지 확인하세요.

**봇은 들어왔는데 받아 적지 않습니다.**
- 서버에서 봇이 **서버 헤드셋 음소거(Server Deafen)** 돼 있으면 소리를 받을 수 없습니다. 봇을 우클릭해 해제하세요.
- **파형** 창에서 소리가 들어오는지 확인하세요.
  - 파형이 움직이는데 받아 적지 않는다면 `vadThreshold`를 낮춰 보세요(예: 0.5).
  - 파형이 일자라면 자동 증폭(`autoGain`)이 켜져 있는지 확인하세요.
- 처음 시작할 때는 Whisper 모델을 올리는 데 몇 초 걸립니다.

**화자 이름이 숫자로만 나옵니다.**
- 봇이 참가하기 전부터 채널에 있던 사람은 이름을 따로 조회합니다. 보통 몇 초 뒤 채워지며, 그다음 발화부터 이름이 표시됩니다.
- 계속 숫자라면 `knownUsers` 표에서 `name`을 직접 입력하세요.

## 보안

- 봇 토큰은 이 PC의 HearingAid 폴더 `profiles\<프로필 이름>.json`에 **평문으로** 저장됩니다. 이 폴더를 다른 사람에게 보내거나 클라우드에 공유하지 마세요.
- 토큰이 유출됐다고 의심되면 개발자 포털에서 즉시 **Reset Token**을 누르세요.
- 봇에는 `View Channels`와 `Connect` 외의 권한을 주지 마세요. 봇이 하는 일은 음성 채널에 들어가 듣는 것뿐입니다.
