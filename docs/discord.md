# Discord 음성 채널 받아 적기

Discord 봇을 음성 채널에 들여보내 **말하는 사람마다 따로** 받아 적습니다. 목록에 누가 말했는지가 함께 표시됩니다.
처음 한 번 봇을 만들어 두면, 그다음부터는 HearingAid에서 **시작**만 누르면 됩니다.

> **먼저 알아둘 점**
> 봇은 음성 채널 참가자 목록에 다른 사람에게도 보입니다. 다른 사람의 말을 받아 적는 것이므로, 함께 있는 사람들에게 미리 알리고 동의를 받으세요.

**준비물:** Discord 계정, 봇을 넣을 서버의 **서버 관리하기** 권한(내 서버가 아니면 관리자에게 4단계를 부탁), 약 10분

아래 순서대로 한 단계씩 따라 하세요.

---

## 1단계. 애플리케이션 만들기

1. [Discord 개발자 포털](https://discord.com/developers/applications)에 Discord 계정으로 로그인합니다.
2. 오른쪽 위 **New Application**을 누릅니다.
3. 이름을 입력합니다(예: `HearingAid`). 이 이름이 음성 채널에 봇 이름으로 표시됩니다.
4. 약관에 동의하고 **Create**를 누릅니다.

## 2단계. 봇 토큰 복사하기

1. 왼쪽 메뉴에서 **Bot**을 엽니다.
2. **Reset Token**을 누르고, 확인 창에서 **Yes, do it!**을 누릅니다.
3. 토큰이 한 번만 표시됩니다. **Copy**를 눌러 메모장에 잠시 붙여 둡니다. (6단계에서 씁니다)

> 토큰은 봇의 비밀번호입니다. 다른 사람에게 보여주거나 인터넷에 올리지 마세요.

## 3단계. 초대 링크 만들기

1. 왼쪽 메뉴에서 **OAuth2**를 엽니다.
2. 아래로 내려 **OAuth2 URL Generator**를 찾습니다.
3. **Scopes** 목록에서 **`bot`** 을 체크합니다.
4. 아래에 **Bot Permissions** 목록이 나타납니다. 다음 두 개를 체크합니다.
   - **View Channels**
   - **Connect**
5. 맨 아래 **Generated URL** 오른쪽의 **Copy**를 누릅니다.

## 4단계. 봇을 서버에 초대하기

1. 3단계에서 복사한 주소를 브라우저 주소창에 붙여 넣고 엽니다.
2. **서버에 추가** 목록에서 봇을 넣을 서버를 고릅니다.
3. **계속하기** → **승인**을 누릅니다.
4. Discord 앱에서 그 서버의 멤버 목록에 봇이 보이면 성공입니다.

여러 서버에서 쓰려면 서버마다 같은 주소로 초대합니다.

## 5단계. 내 사용자 ID 복사하기

봇은 지정한 사람(보통 나)이 있는 음성 채널을 따라 들어갑니다. 그 사람을 숫자 ID로 알려 줍니다.

1. Discord 앱에서 **사용자 설정(톱니바퀴)** → **고급**을 엽니다.
2. **개발자 모드**를 켭니다.
3. 왼쪽 아래 내 프로필을 **우클릭** → **사용자 ID 복사**를 누릅니다. 메모장에 붙여 둡니다.

`123456789012345678`처럼 17~20자리 숫자입니다.

## 6단계. HearingAid에 입력하기

1. HearingAid 메인 화면에서 프로필 목록 옆의 **⚙ 편집**을 누릅니다.
2. 위쪽 **+ 새 프로필**을 누르고 이름(예: `디스코드`)을 입력합니다.
3. **오디오 소스**에서 종류를 **Discord 음성 채널 (NetCord)** 로 고릅니다.
4. 두 칸을 채웁니다.

   | 칸 | 넣을 값 |
   |---|---|
   | `token` | 2단계에서 복사한 토큰 |
   | `targetUserId` | 5단계에서 복사한 사용자 ID |

   나머지 칸은 그대로 둡니다.
5. **저장**을 누릅니다.
6. 오른쪽 위 **이 프로필 사용**을 누르고 창을 닫습니다.

## 7단계. 시작하기

1. Discord에서 음성 채널에 들어갑니다.
2. HearingAid에서 **▶ 시작**을 누릅니다.
3. 몇 초 뒤 봇이 같은 음성 채널에 들어오고, 아래쪽 상태 표시줄에 `listening...`이 나타납니다.
4. 누군가 말하면 목록에 말한 사람 이름과 함께 적힙니다.

이제 내가 다른 채널로 옮기면 봇도 따라 옮기고, 음성 채널을 나가면 봇도 나가서 기다립니다.

다 끝났습니다. 다음부터는 Discord 음성 채널에 들어간 뒤 **▶ 시작**만 누르면 됩니다.

---

## 잘 안 될 때

**`대상 사용자가 음성 채널에 없습니다. 대기 중...`이 계속 뜹니다.**
- 내가 음성 채널에 들어가 있는지 확인하세요.
- 그 서버의 멤버 목록에 봇이 있는지 확인하세요. 없으면 4단계를 다시 합니다.
- `targetUserId`에 서버 ID나 채널 ID를 넣지 않았는지 확인하세요. 5단계의 **사용자 ID 복사**로 얻은 값이어야 합니다.

**`음성 채널 참가 실패`가 뜹니다.**
- 그 음성 채널만 봇이 못 들어가게 막혀 있을 수 있습니다. 음성 채널 옆 톱니바퀴 → **권한** → **역할/멤버 추가**로 봇을 추가하고, **채널 보기**와 **연결**을 ✅로 바꾸세요.
- 인원 제한이 꽉 찬 채널에는 들어갈 수 없습니다.

**시작하자마자 오류가 나거나 접속이 안 됩니다.**
- 토큰을 다시 확인하세요. 앞뒤에 공백이 섞였거나, 그 뒤에 **Reset Token**을 또 눌러 무효가 됐을 수 있습니다. 2단계에서 새로 받아 넣으세요.

**봇은 들어왔는데 받아 적지 않습니다.**
- 봇 이름 옆에 헤드셋 음소거 표시가 있으면, 봇을 우클릭해 **서버 헤드셋 음소거**를 해제하세요.
- 메인 화면의 **파형**에서 소리가 들어오는지 확인하세요. 파형이 움직이는데 적히지 않으면 [문제 해결](app/troubleshooting.md) 문서를 보세요.

**화자 이름이 숫자로 나옵니다.**
- 이름을 가져오는 데 몇 초 걸립니다. 다음 발화부터 이름이 표시됩니다.
- 계속 숫자라면 프로필의 `knownUsers` 표에서 `name` 칸에 직접 입력하고 저장하세요.

---

권한이 왜 필요한지, 각 설정 항목의 뜻, 화자별 보정과 보안 정보는 [Discord 상세 정보](discord-details.md)에 정리했습니다.
