# Discord 상세 정보

[Discord 음성 채널 받아 적기](discord.md)의 단계를 따라 했다면 이 문서는 읽지 않아도 됩니다.
권한이 왜 필요한지, 설정 항목의 뜻, 동작 방식을 알고 싶을 때 참고하세요.

## 동작 방식

1. 봇이 토큰으로 Discord에 접속합니다.
2. 봇이 들어가 있는 서버 중에서 `targetUserId` 사용자가 있는 음성 채널을 찾아 같이 들어갑니다.
3. 채널에서 들리는 소리를 사람별로 받아(Discord는 말하는 사람마다 음성을 따로 보냄) 사람마다 따로 받아 적습니다.
4. 대상 사용자가 다른 채널로 옮기면 따라가고, 음성 채널을 나가면 봇도 나가서 기다립니다.

## 필요한 권한과 이유

봇은 음성 채널에 들어가 듣기만 합니다. 그래서 아래 권한만 있으면 됩니다.

| 구분 | 항목 | 이유 |
|---|---|---|
| OAuth2 Scope | `bot` | 봇으로 서버에 참가 |
| Bot Permission | View Channels | 음성 채널 목록과 대상 사용자가 있는 채널을 봄 |
| Bot Permission | Connect | 음성 채널에 들어감 |

- 위 두 권한의 권한 정수는 `1049600`(View Channels 1024 + Connect 1048576)입니다.
- 초대 링크를 직접 만들 수도 있습니다. 개발자 포털 **General Information**의 **Application ID**를 넣으세요.

  ```
  https://discord.com/oauth2/authorize?client_id=<APPLICATION_ID>&scope=bot&permissions=1049600
  ```

### Gateway 인텐트

HearingAid는 `Guilds`와 `GuildVoiceStates` 인텐트만 씁니다. 둘 다 특권(Privileged) 인텐트가 아니라서, 개발자 포털 **Bot** 메뉴의 **Privileged Gateway Intents**(Presence / Server Members / Message Content)는 건드릴 필요가 없습니다.
화자 이름은 음성 채널 정보(서버 별명 → 표시 이름 → 사용자명 순)에서 가져오므로 Server Members 인텐트도 필요 없습니다.

### 채널별 권한

서버 전체에서 권한을 줬어도, 음성 채널이나 카테고리마다 권한을 따로 막아 둘 수 있습니다.
`@everyone`이나 봇의 역할에 **채널 보기**·**연결**이 ❌로 돼 있는 채널에는 봇이 들어가지 못합니다. 그 채널의 **권한**에 봇(또는 봇 역할)을 추가해 두 권한을 ✅로 바꾸세요.

### 선택 사항: 다른 사람이 내 봇을 초대하지 못하게

기본 설정에서는 초대 링크를 아는 사람이면 누구나 내 봇을 자기 서버에 초대할 수 있습니다(초대해도 토큰이 없으니 봇을 조종할 수는 없습니다).
막고 싶다면 **Installation**에서 **Install Link**를 `None`으로 바꾼 뒤, **Bot**의 **Public Bot**을 끄세요.

## 설정 항목

프로필의 오디오 소스를 **Discord 음성 채널**로 고르면 나오는 칸입니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| `token` | (필수) | 봇 토큰 |
| `targetUserId` | (필수) | 봇이 따라다닐 사용자의 ID |
| `knownUsers` | 비어 있음 | 화자 목록(`userId`/`name`/`gain`/`lowPassCutoffHz`/`lowPassQ`). 처음 말한 사람이 자동으로 추가됨 |
| `gain` | 1.0 | 새로 추가되는 화자의 기본 증폭 배율 |
| `autoGain` | 켜짐 | 작은 목소리를 자동으로 키움. 화자마다 따로 맞춤 |
| `lowPassCutoffHz`, `lowPassQ` | 7000, 0.707 | 음질 변환(48kHz → 16kHz)용 필터. 보통 그대로 둠 |
| `vadThreshold` | 0.7 | 말소리 판단 기준(0~1). 잡음이 말로 잡히면 올리고, 말이 잘 안 잡히면 내림 |
| `minSilenceMs` | 600 | 이만큼 조용하면 한 문장이 끝난 것으로 봄 |
| `speechPadMs` | 200 | 말 시작 직전 소리를 이만큼 더 포함 |
| `minSpeechMs` | 500 | 이보다 짧은 소리는 버림(기침, 키보드 소리 등) |

## 화자 이름과 화자별 설정

- 처음 말한 사람은 자동으로 `knownUsers`에 추가되고, 이름은 서버 별명 → 표시 이름 → 사용자명 순으로 채워집니다. 이름을 가져오기 전에는 잠깐 사용자 ID(숫자)로 표시됩니다.
- `knownUsers` 표의 `name`을 고치고 저장하면, 캡처 중이어도 다음 발화부터 바뀐 이름으로 표시됩니다.
- `knownUsers`의 `gain`, `lowPassCutoffHz`, `lowPassQ`는 사람별 소리 보정값입니다. 정지 후 다시 시작해야 반영됩니다.
- 화자마다 다른 Whisper 모델을 쓰려면 [모델](app/models.md) 문서의 "화자별 모델"을 보세요.

## 상태 메시지

| 상태 메시지 | 의미 |
|---|---|
| `Discord 게이트웨이 연결됨 — 대상 사용자 탐색 중...` | 봇이 Discord에 접속했고 서버 목록을 받는 중 (2초 정도) |
| `음성 채널 참가 중...` | 대상 사용자가 있는 음성 채널에 들어가는 중 |
| `Discord 음성 채널 (...) — listening...` | 받아 적기 준비 완료 |
| `대상 사용자가 음성 채널에 없습니다. 대기 중...` | 대상 사용자가 음성 채널에 들어가면 자동으로 따라 들어감 |

## 보안

- 봇 토큰은 HearingAid 폴더의 `profiles\<프로필 이름>.json`에 **평문으로** 저장됩니다. 이 폴더를 다른 사람에게 보내거나 클라우드에 공유하지 마세요.
- 토큰이 유출됐다고 의심되면 개발자 포털 **Bot** 메뉴에서 즉시 **Reset Token**을 누르고, 새 토큰을 프로필에 넣으세요. 예전 토큰은 바로 무효가 됩니다.
- 프로필 편집 화면의 `token` 칸은 화면 공유 중에도 보이지 않도록 가려서 표시됩니다. 옆의 **보기**를 체크하면 잠깐 확인할 수 있습니다.
